# UTH 探针 · Chrome 插件使用说明

对照 8 月开源算法做的小工具：**安全检测**（UTH 公开标签启发式匹配）+ **分数估算**（公开互动 × `param.rs` 权重）。

---

## 它做什么

| 功能 | 依据 | 结果 |
|------|------|------|
| 作者身份 | 时间线抓头像 + `@handle` | 圆形头像叠在检验单上，可点进主页 |
| 安全检测 | 报告第四章 UTH 帖子级标签 + 启发式 | 未命中 → 绿色 CLEAR；命中 → FLAG / HOLD |
| 分数估算 | 报告第一章权重表。缺项按 **0** | Σ 权重 × P |
| 建议 | 按标签命中 + 赞/回复结构 + 帖龄 | 3–6 条可执行建议 |
| 下载报告 | 生成 PNG 检验单 | 含头像、ID、分数、建议、[@misaENFP](https://x.com/misaENFP) 水印 |

品牌头像来自 [Misa_OKX @misaENFP](https://x.com/misaENFP)。分析对象的圆形头像和 ID 来自当前这条帖。

这不是 X 后台的真实标签，也不是 Phoenix 模型输出。绿色只表示「这套公开规则没扫到明显信号」。

## 安装（未上架，本地加载）

1. 打开 Chrome，地址栏进入 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. **加载已解压的扩展程序**，选中本仓库里的 `uth-probe` 文件夹
4. 打开 [x.com](https://x.com)，时间线每条帖右侧动作栏会出现 **探针**

---

## 两种用法

**时间线里点「探针」**  
检验单三个页签：安全 / 分数 / 建议。底部可 **下载报告**（PNG，带作者圆形头像、@ID、分数和建议）。

改完代码后，到 `chrome://extensions` 点 UTH 探针的 **刷新**，再硬刷新 x.com。

**点浏览器工具栏图标**  
可以粘贴正文自己分析，或点「读取当前页帖子」（需正在浏览 x.com）。

分数页可以勾选：

- **互关原创**：回复权重 5 → 20（对应双向关注加成）
- **非粉路径 ×0.75**：模拟 OON 折扣

帖龄超过 48 小时会提示：分再高也被 AgeFilter 滤掉。

---

## 分数怎么算

```
P(行为) = 该行为次数 / 浏览量   （没有浏览量则 P = 0）
分 = Σ (权重_i × P_i)
```

页面通常能读到：赞、回复、转发、浏览量。  
读不到、因此恒为 0：复制链接（权重 20）、私信分享、关注、举报、停留等。

所以估算分会**系统性偏低**——缺的是算法最贵的那几项。用它比较「同一帖补上浏览量之后，赞和回复谁在贡献」，不要拿去对标真实 For You 名次。

---

## 安全检测覆盖的标签

NSFW 族、血腥、Spam / SpamHighRecall、恶意链接 / DoNotAmplify、FOSNR（辱骂、仇恨、暴力言论、公民诚信）、自残鼓励 → Bounce。

账号级标签（头像 NSFW、整号 SpamHighRecall 等）插件看不到，请用官方 [Under the Hood](https://x.com/i/under_the_hood)。

## AI 复核（可选，DeepSeek）

本地规则是关键词启发式，识别不了讽刺、谐音、变体词。绑定自己的 DeepSeek API Key 后，安全页会在规则之外加一层语义复核：

1. 右键扩展图标 → **选项**（或 popup 右上角 **AI** 按钮）打开设置页
2. 填入 [platform.deepseek.com](https://platform.deepseek.com) 创建的 API Key，勾选启用，保存
3. 再分析帖子时，安全页先秒出规则结果，随后显示「DeepSeek 复核完成」，AI 补充的标签会带 **AI** 角标

说明：

- Key 只存浏览器本地（`chrome.storage.local`），不会上传
- 启用后，被分析帖子的**文本和链接**会发送到 api.deepseek.com；关掉开关即回到纯本地模式
- 默认模型 `deepseek-v4-flash`（可切 `deepseek-v4-pro`）；旧的 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07 停用，插件会自动迁移旧配置。AI 判定同样只是估计，不代表 X 官方结论
